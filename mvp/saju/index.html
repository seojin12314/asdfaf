심층 리포트

    일간을 중심으로 본 원국의 구조는 다음과 같다. 월지에 자리한 기운이 전체의 흐름을 주도하며, 시주의 글자가 이를 보조한다. 특히 두 번째 대운에서 들어오는 기운은 현재의 고민과 직접 연결된다.

    다음 해 세운이 들어오는 자리는 재성과 관성이 교차하는 지점으로, 상반기와 하반기의 체감이 크게 달라진다. 구체적으로는

    결제 즉시 발행 · 디지털 콘텐츠는 발행 후 청약철회가 제한됩니다

    근거 데이터
    결제 · 토스페이먼츠/포트원 연동 지점

    상품심층 리포트 1회
    금액
    발행결제 즉시

    MVP 콘티: 실제 결제가 일어나지 않습니다. 운영에서는 결제 승인 콜백 → 리포트 생성 큐 → 알림톡 링크 순서로 자동 처리됩니다.

    공유 카드 (1080×1350)

    이미지를 길게 눌러 저장하거나 공유하세요. 운영에서는 카카오톡·인스타 공유 버튼이 붙습니다.

    콘티 흐름: 시작 → 고민 → 캐릭터 → 정보 → 리딩 → 캐릭터 시트 → 심층 리포트(결제) → 공유 카드
