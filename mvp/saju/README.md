# 사주도감 MVP 콘티

캐릭터 하나 × 명식 하나 × 리포트 하나. 캐릭터가 읽어 주는 내 명식.
클릭해서 끝까지 흐름을 볼 수 있는 **동작하는 콘티**다. 서버 없이 정적 파일만으로 돌아간다.

- 메인은 **캐릭터 선택**으로 시작한다. 캐릭터 4인 + 전문가 1인(정경진, ₩39,900). 각자 잘 보는 명식이 다르다.
- **MBTI 사주**는 별도 상품(₩9,900)으로 분리되어 있다.
- 심층 풀이는 데이터 기반 **17장**, 모든 조합에서 **모바일 15화면(6,750자) 이상**(테스트로 보장).
- 캐릭터 이미지는 `assets/characters/<id>/`에 넣으면 자동 반영되고, 없으면 엠블럼으로 대체된다. 제작 스펙은 [docs/character-art-brief.md](../../docs/character-art-brief.md).

## 미연시 연출(2026-10-30 추가)

캐릭터 카드를 누르면 `vn.js`가 전체 화면 무대를 연다. 흐름은 비주얼 노벨과 같다.

| 단계 | 연출 | 파일 |
|---|---|---|
| 등장 | 배경 3레이어(원경 줌·입자 상승·전경 패럴랙스) + 캐릭터별 입자(불씨·엽전·달빛·꽃잎·빛줄기·별) + 캐릭터별 등장 애니메이션 + 이름표 | `vn.css`, `vn.js` |
| 도입·선택지 | 캐릭터가 말을 걸고(타자 효과, 표정 교체: 기본·웃음·진지·말하기) 고민 선택지 3개를 준다. 선택에 따라 대답과 이후 풀이의 초점이 달라진다 | `vn-scripts.js` |
| 정보 | "정보를 주겠어?" 흐름으로 이름→성별→생일→시각을 대화창 안에서 한 항목씩 받는다. 이미 명식이 있으면 "그대로/다시" 선택. 홍염은 재회 선택 시 상대 생일(궁합)도 받는다 | `vn.js` `ask()` |
| 소환·분석 | 소환 링 + wake 연출 후, 대사를 읊으며 떠 있는 패널에 원국·오행 레이더·십신 스탯·글자(배우자성, 대운, 세운, 신강신약)·열두 달 흐름표가 차례로 뜬다. 경고 대사는 화면 흔들림·어두워짐, 강점 대사는 섬광·후광 | `vn-scripts.js` `beats()` |
| 맺음 | 캐릭터 시트로 인계하거나 다른 캐릭터에게 간다 | `vn.js` `finish()` |

**풀이 초점 규칙(캐릭터별 고정)**: 윤슬(flame)=연애·배우자성·궁합(상대 입력 시 일간 합·일지 충·오행 보완 판정), 도사=재성·식상·관성 셈과 재성 달, 복순 할머니(granny, 삼신할머니)=자녀복(자녀성 개수·자녀궁 시주·때·아들딸)+올해·내년 세운과 조심할 달, '우리 아이 기질' 고민을 고르면 아이 명식을 받아 아이 기질·칭찬형/규칙형(아이 모드), 헤드헌터=신강신약별 이직 유형·관성 달, **정경진만 전체**(일간·십신·오행·조후·신강신약·용신·대운·세운·배우자·직업·열두 달).

컨트롤: 탭/스페이스/엔터로 진행(타자 중이면 즉시 완성), `자동`으로 자동 진행, `나가기`/ESC로 홈. `prefers-reduced-motion`이면 연출을 줄인다. 헤드리스 검증: `node -e` 로 `SajuVNScripts.SCRIPTS[id].beats(ctx)`를 호출해 6캐릭터×4명식×선택지 전 조합의 대사가 비거나 `undefined`가 섞이지 않는지 확인했다.

## 쉬운 말 층·MBTI 상담사(2026-10-30 추가)

- **쉬운 말(`plain.js`)**: 전문용어를 일반인 말로 자동 변환한다. 한 블록(대사 한 줄·리포트 한 장)에서 용어가 처음 나올 때만 `쉬운 말(원어)`로 병기하고 이후엔 쉬운 말만 쓴다. 치환 뒤 조사(이/가·은/는·을/를·과/와·으로/로)를 받침에 맞게 고치고, 일상어와 겹치는 용어(세운·상관·일주·지지, 한 글자 충·합·형)는 문맥을 제한한다. 상단 `쉬운 말/전문 용어` 버튼으로 끄고 켤 수 있다(localStorage `saju-plain`). 적용 범위: 미연시 대사·패널 제목, 시트 3줄·원국 라벨·근거표, 심층 리포트 전 장, MBTI 카드.
- **MBTI 상담사(`assets/characters/mbti/`)**: MBTI 사주 상품도 미연시로 진행한다. 친절한 과외 선생님 톤의 30대 남성 상담사가 생일→검사 MBTI→추구 MBTI(선택)를 대화로 받고, 세 글자(검사·명식·추구)를 나란히 놓아 축별로 유지·회복·역행 판정과 **사주가 권하는 흐름**을 설명한다(`mbti.js` `advise()`). 결과 화면·심층 리포트(`추구 MBTI로 가는 길` 장)·공유 카드에도 세 글자가 들어간다.

## 캐릭터 말투 층(`tone.js`, 2026-11-01)

리포트(마지막 페이지)는 데이터로는 해요체(쉬운 말)로 만들고, 화면에 그릴 때 `tone.js`가 문장 끝 어절을 캐릭터 말투로 바꾼다. 윤슬=반말(~야/~해), 복순 할머니=반말+~이란다/~렴, 백운 도사=하게체(~이다/~네/~거라), 서지안=합쇼체(~입니다/~십시오), 정경진·도윤=해요체 그대로. 어간 복원은 사전+모음 규칙(ㅂ·르·으 불규칙 일부). 근거(L3)·용어표·질문 제목·다른 상담자 답은 제외하고, 다른 상담자 답과 교차 추천 한 줄은 그 캐릭터 말투로 바꾼다. 캐릭터 색은 `[data-persona]`에서 `--accent`를 다시 묶어 라이트 테마에서도 리포트·시트에 반영된다.

## 계산 규칙(이 MVP가 채택한 것)

- 년주 경계 입춘(황경 315°), 월주 경계 12절기. 황경은 Meeus 저정밀식(시각 오차 약 15분).
- 일주 = (율리우스일수 + 49) mod 60. 2000-01-01 戊午, 1900-01-01 甲戌로 검증.
- 시주: 자시 23:00~00:59. 23시 이후 출생은 **다음 날 일주**(야자시→익일) 채택.
- 진태양시 보정 기본 −30분. 서머타임 미반영. 음력 입력 미지원.
- 십신은 지지의 본기(本氣) 천간으로 계산. 오행 분포는 천간 + 지지 본기 각 1.
- 대운수: 양남음녀 순행(다음 절입까지 일수/3), 음남양녀 역행. 반올림, 1~10. 만 나이 기준.

유파에 따라 다른 선택(야자시 처리, 보정 분, 지장간 가중)은 운영 전환 때 상품 정책으로 확정한다.

## MBTI × 명식 교차 분석 (전제와 규칙)

- **전제**: 사주와 MBTI 사이에 검증된 대응 관계는 없다. 이 기능은 예측이 아니라 "자기 인식(검사)"과 "타고난 기질(명식)"을 나란히 놓고 보게 하는 대화 장치다. 화면의 "추정 근거 보기"에 규칙과 기여 요인을 그대로 노출한다.
- **입력**: 폼에서 평소 검사 MBTI를 네 축 토글로 선택(선택 사항). 건너뛰면 결과 카드에서 나중에 넣고 비교할 수 있다.
- **추정**: 십신 그룹 비율(비겁·식상·재성·관성·인성)과 오행 비율, 일간 음양·오행에 축별 가중치를 곱해 합산하고 tanh로 0~100%로 바꾼다. 가중치는 `mbti.js`의 `RULES`에 있다.

| 축 | 왼쪽 글자로 미는 요인 | 오른쪽 글자로 미는 요인 |
|---|---|---|
| E / I | 식상(표현)·비겁(동료)·火·양간 | 인성(수용)·관성·水·金·음간 |
| S / N | 재성(현실)·관성(규칙)·土·金 | 식상(창의)·인성(사고)·水·木 |
| T / F | 관성(원칙)·재성(계산)·金·水·일간 金水 | 식상(공감)·인성·火·木·일간 木火 |
| J / P | 관성(구조)·인성·재성·土·金 | 식상(즉흥)·비겁(자율)·火·木 |

- **비교**: 축별 일치/불일치와 명식 쪽 강도(%)를 보여 주고, 16가지 조합(검사 글자 × 명식 글자) 문장과 일치 축 수(0~4)별 요약을 붙인다. 공유 카드와 심층 리포트 5장에도 들어간다.
- **운영 전환 시**: 가중치는 실제 이용자 데이터(검사 MBTI 입력값 vs 명식)로 보정할 수 있다. 다만 그것도 "대응 관계 증명"이 아니라 이용자 분포에 맞춘 조정이라는 점을 문구에 유지한다.

## 심층 풀이 17장 구성

요약 → 일간 심층 → 원국 네 기둥 → 원국의 십신 하나씩 → 지지 충·합·형 → 오행 균형과 조후 → 몸의 신호(전통 배속) → 십신 구조 → 신강신약·격·용신(간이) → 대운 → 세운(올해·내년) → 내년 열두 달 흐름표(+올해 남은 달) → 배우자 자리와 배우자성 → 일의 형태 → 캐릭터 고민 특화 장 → 4주 계획(if-then·하지 말 것) → 맺음말과 계산 기준.
장마다 캐릭터의 도입 문장(lead)이 붙고, 고민 특화 장은 캐릭터마다 일간·강한 기운·약한 기운별로 다른 본문이 나온다. 신강신약·격·용신·조후는 간이 판정이며 화면에 "전문가 감수 필요"를 표기한다.

## 전문가 캐릭터(정경진)에 대한 전제

정경진 본인과 실명·직함·초상 사용 동의·계약이 완료됐다(2026-10-30, 사용자 확인). 화면의 동의·감수 관련 표기는 모두 제거했다.

## 검증 지표(출시 후 60일)

무료 결과 완료율, 무료→유료 전환율(목표 2%+), 공유율(목표 K ≥ 0.3), 환불률(<5%), 리포트 원가(<₩1,000), "다른 캐릭터로 다시 보기" 클릭률.

## 3층 리포트(report2.js · report-ui.js · report.css, 2026-10-30)

심층 리포트는 `report.js`(장문 템플릿) 대신 `report2.js`가 만든다. 구조는 L1 결론 화면(정체성 한 줄 · 피해야 할 3가지 · 열두 달 미니맵 · 진입점) → L2 쉬운 설명 7장(각 장은 결론 → 캐릭터 한마디 → 3~5문장 → 시각화 → 피할 것/대신 쌍) → 대신 3개 모음 + 4주 체크(저장) + 맺음 → L3 근거 아코디언(원국표 · 네 기둥 · 충합형 · 신강신약 판정 · 대운표 · 월운표 · 계산 기준 · 용어집).

- **처방 방향은 판정값에서만 나온다**: 신강→식상·재성·관성으로 덜어 쓰기, 신약→인성·비겁 채우기, 중화→조후(계절) 기운. `direction()`이 허용 집합을 정하고 모든 처방·달력 등급·4주 계획이 그 안에서만 생성된다.
- **피할 것 3개** = 원국(매년 일지와 부딪히는 달 + 가장 작은 힘의 행동) · 세운(내년 글자) · 월운(부딪히는 달, 세운과 다른 기둥 우선). 형식 [시기]+[행동]+[대상]. 대신은 1:1 대응, 글자 수 2배 이상, 하나는 빈 기운 채우기(4주 계획과 연결).
- **용어**: L1·L2는 쉬운 말만(비겁→나 자신의 힘, 식상→내보내는 힘, 재성→손에 쥐는 힘, 관성→나를 누르는 힘, 인성→쉬고 배우는 힘, 대운→10년 계절, 세운→올해 날씨, 충→부딪힘, 합→끌림). 한자·분수·절기월·십신 원어는 L3와 용어집에서만.
- **캐릭터 색깔**: 본문 규칙은 공통, 캐릭터는 초점 섹션 확장(윤슬=관계, 백운=힘의 분포/돈, 복순=올해·열두 달, 초롱=아이 전용 텍스트 전체, 서지안=일·분기별 적기)과 섹션마다 캐릭터 말투의 한마디(인용)로 드러난다. 본문은 해요체 하나.
- **검사기**: `node tools/report_lint.cjs [N]` — N개 명식 × 캐릭터 × MBTI 조합을 만들어 합격 기준(방향 일치 · 등급 수식어 · 금지∩추천 직군 공집합 · 조사 미해결 0 · 25자 이상 중복 0 · L1+L2 ≤ 2,500자 · 한자/분수/원어 0 · 쌍 종료 · 세 출처 · 2배 비율 · 공포 단어 0 · 맺음말 손실 언어 0 · 문장 40자 · 단락 3문장 · 해요체)을 검사한다. 1,000개 통과 상태로 커밋한다.

## 캐릭터 렌즈 · 궁합 엔진(2026-10-31)

- **렌즈(`report-lenses.js`)**: 사람들이 그 캐릭터를 누른 이유에 맞춰 심층 7장을 통째로 바꾼다. 백운=내 돈 그릇·돈이 새는 자리·벌 때와 지킬 때·올해 돈 흐름·거래 달력·동업/독립/투자 중 내 길·돈과 가까운 사람. 윤슬=내 연애 모양·끌어들이는 사람·인연의 10년 계절·올해 인연·인연 달력·잘 맞는 상대의 글자·결혼/동거 타이밍. 서지안=시장이 보는 유형·자원 배분·커리어 10년·올해 이직 흐름·분기별 적기·상사/동료 궁합·적합 직무. 복순=가족 자리·올해 지킬 것(몸·돈)으로 6·7장 교체. 초롱=아이 전용 표(report2 내부). 정경진·MBTI=전체. 피할 것 3개·4주 계획·L1 진입점도 렌즈별이다.
- **궁합(`compat.js`)**: 두 명식을 맞댄다. ① 타고난 글자 합·충·생극 ② 여덟 글자 전체의 합·충·형·해·반합(일주 3·월주 2·년시 1 가중) ③ 서로 채워 주는 기운(상대가 내 처방 기운을 가졌는지) ④ 힘의 균형(신강·신약) ⑤ 역할 구도(상대 일간이 나에게 어떤 힘인지, 연애=짝 기운/동업=판을 쥐는 쪽/지인=눈높이) ⑥ 둘 다 좋은 달·한쪽이 흔들리는 달. 점수 15~95(공개 합산), 피할 것/대신 쌍, 리포트 섹션(연애=관계 장, 동업·지인=일 장 대체), 근거 표. 미연시에서는 윤슬(연애, 고민 '그 사람과 맞을까'·'재회')과 백운(홈의 **동업·지인 궁합** 항목, 동업/친구 선택)이 상대 이름·성별·생일을 받아 캐릭터 말투로 읽어 준다. 시트에는 궁합 카드가 붙는다.

## 질문 은행 상품(questions.js, 2026-10-31)

- 영역별 질문 목록: 연인·궁합 20 · 재물·사업 20 · 자녀 20 · MBTI 20 · 심층 정통 30 · 이직·직장 20(캐릭터→영역: 윤슬=연인, 백운=재물, 초롱=자녀, 도윤=MBTI, 정경진·복순=정통, 서지안=이직). 시트의 "질문 고르기" 카드에서 10개를 고른다(추천 10개 자동 채움, ★ 문항은 상대·부모·검사 MBTI 입력이 있어야 열림).
- 결제 후 리포트 = 결론 화면(피할 것 3·달력) → **고른 질문의 답**(명식 기반 2~4문장, 쉬운 말·해요체·40자) → 나머지 문항 잠금 목록 + **+₩5,000 전부 열기** → 전체 흐름 7장(접힘) → 근거 아코디언.
- 답변 생성은 `facts()`(신강신약·방향·십신·오행·짝/자녀 기운·충합형해·신살(역마·도화·화개·백호·귀문)·공망·지장간·대운·세운·월운·궁합·MBTI)에서 조립한다. 초롱 동자는 아이 명식 + 부모 생년월일(선택)을 받아 부모 관점 문항을 연다.
- 검사기: `node tools/qa_lint.cjs [N]` — N개 명식 × 130문항 답변의 문장 길이(정통 48자, 그 외 40자)·해요체·undefined·괄호·조사·(정통 제외) 전문용어를 검사한다.
