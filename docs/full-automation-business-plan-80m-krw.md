- 통화: KRW. 환율 가정 1 USD ≈ ₩1,400 (미확인 가정. 적용 전 당일 환율로 재계산)

## 0. 결론 먼저

### 판정 1. "사업 하나 + 풀 자동화 + 월 8천만"은 성립하지 않는다

보유 자산 중 어느 하나도 단독으로 8천만 원을 자동 생산할 구조가 아니다. 현실적인 형태는 **서로 다른 시장에 걸친 2~3개 자동화 엔진의 포트폴리오**이고, 중립 시나리오에서 18~24개월이 걸린다. 3개월 안에 8천만을 자동으로 만드는 경로는 이 자산 목록에서 찾지 못했다.

### 판정 2. 지금까지의 핵심 수익원은 자동화 확대 대상이 아니라 정리 대상이다

한국인을 대상으로 한 해외 거래소 레퍼럴·페이백 모델은 2026년 들어 형사 리스크 영역에 들어갔다(근거는 §3). 자동화는 게시물·링크·정산 기록을 대량으로 남기므로, 이 모델을 자동화하는 것은 **위험을 자동화하는 것**이다. 기존 거래소 지식과 Respawn Trading 코드는 버리지 않고, **한국 타깃을 완전히 배제한 해외 전용** 구조로만 재활용한다.

### 판정 3. 추천 포트폴리오

| C | 글로벌(영어) 트레이딩 교육 디지털 상품 + 자동 콘텐츠 유입 | B의 유입 장치 겸 독립 매출 | ₩1,000만 |
| 합계 | | | **₩7,500만** (비관 ₩2,300만 / 낙관 ₩1억 5,500만) |

### 판정 4. 병목은 "만들기"가 아니라 "유입"이다

세 엔진 모두 기술적으로는 이미 만들어 본 부품(결제, LLM 큐, 텔레그램 봇, Remotion 렌더, UID 검증)의 재조합이다. 어려운 것은 **사람을 데려오는 자동화**다. 유료 광고만으로는 사주 리포트의 첫 구매 ROAS가 1을 넘기 어렵다는 계산이 나온다(§4.5). 오가닉 콘텐츠 자동화, 결과 카드 공유 루프, 재구매 설계가 없으면 광고비가 매출을 먹는다.

### 판정 5. 타이밍

사주·운세 시장의 최대 수요는 신년운세 시즌(12월~2월)이다. 2027년(정미년) 운세 수요가 시작되는 **2026-12-15 이전에 엔진 A의 MVP를 출시**하는 것이 이 플랜의 첫 데드라인이다.

## 1. 목표와 용어 정의

### 1.1 "월 8천만 원"의 정의

사용자는 "수입"이라고 했다. 이 문서는 **월 매출 8천만 원**을 1차 목표로 잡고, 순이익은 §7에서 따로 계산한다. 순이익 8천만을 원하면 매출 목표는 약 1억 2천만~1억 4천만으로 올라가고, 기간은 6개월 이상 늘어난다. 둘 중 무엇인지 사용자가 확정해야 한다.

### 1.2 "풀 자동화"의 정의

다음 5단계가 사람 개입 없이 돌아가는 상태를 말한다.

1. 고객 획득(콘텐츠 생성·게시, 광고 예산 조절)
2. 결제와 이행(상품 생성·전달)
3. 1차 CS(환불, 재발송, FAQ 응답)
4. 정산(페이백 계산·지급, 매출 집계)
5. 모니터링(장애·이상치 알림, 자동 복구)

사람의 일은 **주 5시간 이하의 승인 큐 처리**로 제한한다. 법률·세무·파트너 계약·초기 광고 소재 승인은 자동화되지 않으며, 이 부분까지 0으로 만드는 것은 목표가 아니다. 완전 무인은 존재하지 않는다는 전제로 설계한다.

### 1.3 "내가 만들 수 있다"의 검증

배경 자료 §12·§14 기준으로, 세 엔진은 다음 보유 부품의 조합이다.

| 필요 부품 | 보유 기록 |
|---|---|
| 결제 연동 웹앱(반응형·PWA) | 상태창 시제품, TetherRoad, Respawn Trading |
| LLM 호출 큐·비용 통제·중복 방지 | Signalmarket, Briefing Hub |
| 콘텐츠 자동 생성·렌더(TTS·자막·차트) | Synapse Video, Chartlas, Remotion·FFmpeg·ElevenLabs |
| 다국어 번역·배포 | 텔레그램 다국어 번역 봇, 영어 전자책 제작 |
| UID 검증·파트너 API·정산 대조 | Bitunix 회원 관리 도구(API 미연결 상태) |

만들 수 있다. 단, 배경 자료 §24가 말하듯 **원고·코드·캐릭터의 법적 소유권과 상업 이용 범위가 미확인**이다. 공동 작업자나 파트너사(Bitunix 브랜드판 등)와 얽힌 자산은 Phase 0에서 정리한다.

### 3.2 함의

1. **자동화는 증거를 대량 생산한다.** 자동 게시물, 추천 링크, 페이백 정산 기록은 모두 "수수료를 받고 홍보한" 기록이다. 수동으로 소량 운영할 때보다 자동화할 때 법적 노출이 커진다.
2. **파트너사 자체가 사라질 수 있다.** 차단·주소 변경·한국 철수가 이어지면 정산도 끊긴다. 사용자가 중시하는 "파트너의 자금관리 신뢰"가 구조적으로 보장되지 않는 영역이 됐다.
3. **한국어 콘텐츠 + 레퍼럴 링크 조합은 FIU의 국내 영업 판단 기준(한국어 사이트, 한국인 대상 마케팅)에 정확히 들어맞는다.**

### 3.3 조치

1. 한국어로 노출 중인 모든 거래소 추천 링크·코드·페이백 안내를 채널별로 인벤토리화하고 노출을 중단한다.
2. 특정금융정보법을 다루는 변호사에게 1회 자문을 받는다. 질문: 기존 한국 회원의 미지급 페이백 정산 처리, 해외 전용 전환 시 한국 거주자 차단의 충분성, 과거 활동의 소급 리스크.
3. 파트너사(Bitunix 등)에 한국 타깃 활동 중단과 해외 전용 전환을 서면으로 통보한다.
4. 엔진 B는 §5.1의 조건을 모두 충족한 뒤에만 가동한다.

## 4. 엔진 A — 캐릭터형 AI 사주·운세 플랫폼

### 4.1 왜 사주인가

- **수요가 입증된 시장이다.** 점신(테크랩스)은 2023년 매출 약 830억 원·영업이익 약 100억 원으로 보도됐고, 포스텔러(운칠기삼)는 2024년 연매출 100억 원을 넘겼으며 MAU 약 140만(해외 40만 포함)으로 보도됐다. 2026년 2월 기사는 운세 앱 누적 다운로드 1,700만 건을 보도했다. 시장 규모 추정은 출처별로 디지털 운세 약 3,000억(수년 전 추정)에서 점술 전체 1조 4천억~4조까지 편차가 크다. 숫자 자체보다 "유료 결제가 상시로 일어나는 시장"이라는 점이 중요하다. 출처: [ZDNet Korea](https://zdnet.co.kr/view/?no=20250203104315), [서울경제](https://www.sedaily.com/article/13668098), [한국경제](https://www.hankyung.com/article/2026021070861), [매거진한경](https://magazine.hankyung.com/business/article/202405226315b)
- **100% 자동 이행이 가능한 디지털 상품이다.** 결제 즉시 리포트가 생성·전달되고 재고·배송·사람 상담이 없다.
- **재구매 트리거가 구조적으로 존재한다.** 신년, 연애 상대 변경, 이직·창업 결정, 가족 이벤트. 운세는 "한 번 사면 끝"이 아니다.
- **규제 부담이 낮다.** 금융·의료와 달리 운세 콘텐츠 자체에는 인허가가 없다(§4.8의 일반 소비자법은 적용).
- **사용자 자산과 맞는다.** 캐릭터 5종 구상, 고민·욕망·불안을 상품명으로 바꾸는 기획 경험, 페르소나 유지 운영, 공유 이미지 제작, 상태창의 시각화 자산을 그대로 쓴다.

**반론도 적는다.** 점신 MAU는 2025-01 약 113만에서 2026-01 약 88만으로 감소했다는 보도가 있다. 시장이 포화·정체일 수 있다는 신호다. 다만 종합운세 앱의 정체와 "문제 중심·캐릭터형 리포트"의 수요는 다른 축이며, 이것이 성립하는지가 이 엔진의 핵심 검증 과제다.

### 4.2 포지셔닝

- 기존 앱은 **종합운세 백화점**이다(오늘의 운세, 토정비결, 궤도형 메뉴).
- 우리는 **고민 1개 × 캐릭터 1명 × 리포트 1개**다. 사용자가 이미 설계한 구조를 그대로 쓴다.

| 캐릭터 | 고민 영역 | 상품명 예시 (문제 중심) |
|---|---|---|
| 홍염의 여신 | 연애·재회·궁합 | 그 사람 속마음 사주 / 내 연애가 꼬이는 이유 |
| 도사님 | 돈·사업·직업 | 돈 새는 구멍 분석 / 내 사업 타이밍 |
| 할머니 | 한 해·가족·인생 흐름 | 2027 정미년 내 위험 구간 / 올해 피해야 할 달 |
| 애기동자 | 자녀·2세 | 아이 기질 사주 / 부모-자녀 궁합 |
| 냉철한 헤드헌터 | 직업·커리어 | 이직 타이밍 진단 / 내게 맞는 일의 형태 |

- **차별화 레버: 결과를 "캐릭터 시트"로 시각화한다.** 상태창 프로젝트의 6능력치·스탯 카드 자산을 사주 결과에 적용한다. 공유하고 싶은 이미지가 유입 비용을 낮춘다. 이 방향이 효과적인지는 공유율로 측정한다(§4.5).

### 4.4 유닛 이코노믹스 (가정)

- 리포트 1건 생성: 입력 약 1.5K 토큰 + 출력 약 4K 토큰. 중급 모델 기준 **수백 원 이하**로 추정. 동일 사주 조합·동일 상품은 캐시로 재사용해 원가를 더 낮춘다. 실측 후 확정.
- 결제 수수료 약 3.3~3.5%, 인프라 건당 수 원.
- **매출총이익률 90% 이상**(마케팅 제외)으로 추정.

### 4.5 유입 모델과 유료 광고 ROAS 계산

유료 광고 가정: CPC ₩500, 랜딩→무료 결과 완료 40%, 무료→유료 전환 3~5%, ARPPU ₩15,000.

| 항목 | 값 |
|---|---|
| 클릭 1,000회 비용 | ₩500,000 |
| 무료 결과 완료 | 400명 |
| 유료 전환 | 12~20명 |
| 첫 구매 매출 | ₩180,000~₩300,000 |
| **첫 구매 ROAS** | **0.36~0.60** |
| 재구매 포함 LTV 2.5배 가정 시 | 0.9~1.5 |

**결론: 유료 광고만으로는 수익이 나지 않는다.** 광고는 (1) ROAS 임계값을 넘긴 검증 소재의 확장과 (2) 무료 결과 이용자 리타기팅에만 룰 기반으로 집행한다. 유입의 본체는 다음 세 가지 오가닉 자동화다.

1. **숏폼 자동 파이프라인**: 캐릭터별 "이런 사주의 특징" 시리즈. 기존 Remotion·TTS·자막 파이프라인 재사용. YouTube Shorts·Instagram Reels·TikTok 동시 게시. 광고 수익은 기대하지 않는다(§6.3). 목표는 링크 클릭.
2. **결과 카드 공유 루프**: 무료 결과 → 캐릭터 시트 이미지 → 카카오톡·인스타 공유 → 신규 방문. 공유율·공유당 신규 방문을 측정해 K-factor를 추적한다. K ≥ 0.3이 되지 않으면 카드 디자인·문구를 반복 실험한다.
3. **검색 롱테일**: "2027 정미년 운세", "을사일주 연애", "무토 일간 직업" 같은 수천 개 조합 페이지를 템플릿으로 자동 생성한다. 신년 시즌 검색량이 가장 크므로 12월 전에 인덱싱이 끝나야 한다.

### 4.7 시스템 아키텍처

```
[유입]  숏폼 파이프라인(Remotion+TTS) / SEO 템플릿 페이지 / 공유 카드
   ↓
[웹앱]  Next.js + Supabase (Auth, DB, Storage) / 반응형·PWA
   ↓
[사주 계산]  만세력 결정론 엔진 (코드) ──→ 사주 원국·대운·세운 구조화 데이터
   ↓
[리포트 생성]  LLM 큐 (캐릭터 프롬프트 × 상품 템플릿 × 구조화 데이터) + 캐시
   ↓
[결제]  토스페이먼츠 또는 포트원 / 통신판매업 신고 / 전자상거래법 고지
   ↓
[전달]  웹 리포트 + 캐릭터 시트 이미지(서버 렌더) + 카카오 알림톡 링크
   ↓
[리텐션]  월초 브리핑 푸시 / 상대 변경·이직 시 재진단 트리거 / 구독
   ↓
[운영]  매출·원가·전환 일간 리포트 → 텔레그램 / 승인 큐(광고 소재, 신규 캐릭터 프롬프트) / 이상치 알림
```

**기술적으로 가장 중요한 결정**: 사주 계산(절기·만세력·대운 계산)은 **LLM이 아니라 결정론 코드**가 한다. LLM에게 생년월일시를 주고 사주를 뽑게 하면 오류가 섞이고, 오류가 섞인 운세 서비스는 환불과 평판 문제로 바로 이어진다. LLM은 구조화된 사주 데이터를 캐릭터 말투로 해석하는 역할만 맡는다. 알려진 사주 50건 이상을 기존 서비스 결과와 대조해 계산 엔진 정확도를 먼저 검증한다.

**원가 통제**: 동일 사주·동일 상품 캐시, 모델 티어 분리(무료 결과는 저가 모델, 유료는 상위 모델), 월 AI 원가 상한 알림.

## 5. 엔진 B — 해외 전용 거래소 비교·페이백 플랫폼

### 5.1 가동 전제 조건 (하나라도 빠지면 가동하지 않는다)

1. 한국어 페이지·한국어 SNS·한국어 고객 응대 **전면 없음**.
2. 한국 IP 접속 차단(geo-block) + 약관에 한국 거주자 이용 금지 명시 + 가입 시 거주국 확인.
3. 특금법 변호사 자문에서 위 조치의 충분성 확인.
4. 타깃 국가별 금융 프로모션 규제 확인. 최소한 다음은 **제외**: 한국, 일본(무등록 거래소 홍보 규제 강함), 영국(2023년 10월부터 소비자 대상 가상자산 프로모션 규제), 미국, 캐나다. 이 목록은 출발점이며, 국가별 확인은 거래소 파트너 매니저의 승인 국가 목록과 교차한다.
5. 파트너 거래소의 제휴 약관·커미션율을 **서면으로** 확인(검색된 "최대 50%"는 홍보 사이트 수치로 미검증).

### 5.2 타깃 시장 (가설)

- 1차: 영어 글로벌(허용 국가 화이트리스트 방식)
- 2차: 베트남어·인도네시아어·터키어 (선물 거래 수요가 크다는 가설. 각국 규제와 파트너 승인 확인 후)
- Respawn Trading의 다국어 구조와 텔레그램 다국어 봇을 그대로 쓴다.

### 5.3 수익 수학

변수: 월 거래량 V, 평균 수수료율 f, 제휴 커미션율 c, 사용자 페이백 비율 r(커미션 대비).

- 가정: f = 0.04% (Bitunix 선물 메이커 0.02% / 테이커 0.06%의 혼합, 출처: [Traders Union](https://tradersunion.com/brokers/crypto/view/bitunix/fees/)), c = 40% (미검증), r = 50%
- 순수익 = V × 0.0004 × 0.4 × 0.5 = **V × 0.00008**

| 목표(월) | 필요 거래량 | 활성 트레이더(인당 월 $1.5M 명목 가정) | 등록 회원(활성률 20% 가정) |
|---|---|---|---|
| ₩2,500만 (≈$17,900) | 약 $2.2억 | 약 150명 | 약 750명 |
| ₩8,000만 (≈$57,000) | 약 $7.1억 | 약 475명 | 약 2,400명 |

거래량은 시장 사이클에 강하게 연동된다. 하락장에서 선물 거래량은 흔히 절반 이하로 줄어드므로, 이 엔진의 매출은 **변동성 자산**으로 취급하고 포트폴리오 비중을 1/3 이하로 둔다.

### 5.4 자동화 설계

```
가입(허용국 확인) → 거래소 가입 유도(제휴 링크) → UID 입력
   → 파트너 API로 UID 소속·거래량 자동 검증 (기존 도구의 API 연결 완성)
   → 주간 페이백 자동 계산 (수수료 × c × r, 거래소별 산식 분리)
   → 자동 지급 (USDT 온체인 또는 거래소 내부 이체, 지급 한도·2중 확인)
   → 사용자 대시보드 (거래량·페이백·지급 이력)
   → 정산 대조 (파트너 정산서 vs 내부 계산, 불일치 시 보류 + 알림)
```

배경 자료 §3·§11의 원칙을 그대로 적용한다: API 응답 성공 여부가 아니라 사업 코드까지 확인, 일부 계정만 정상일 때 전체 합계를 완전한 것처럼 표시하지 않음, UID 충돌·누락은 자동 처리하지 않고 보류.

### 5.5 리스크

| 리스크 | 대응 |
|---|---|
| 파트너 거래소 정산 지연·조건 변경·폐업 | 거래소 2~3곳 분산, 미정산 페이백은 수령 후 지급 원칙 |
| 타깃 국가 규제 변경 | 분기별 국가 목록 재검토, 즉시 차단 가능한 국가 플래그 |
| 한국 이용자 유입(VPN 등) | 거주국 확인·한국어 UI 없음·의심 계정 보류. 완전 차단은 불가능함을 인정하고 법률 자문에 반영 |

| 시장 침체 | 포트폴리오 비중 상한 1/3 |

## 6. 엔진 C — 글로벌 트레이딩 교육 디지털 상품 + 자동 콘텐츠 유입

### 6.1 상품

- Trading Bible 20권(영어판 제작 기록 있음)을 재편집: 단권 $19, 번들 $49~$99, 워크북·체크리스트 부가.
- 판매 채널: Merchant of Record형 플랫폼(글로벌 결제·부가세 처리 자동) 또는 자체 결제. 초기에는 플랫폼으로 시작해 운영 부담을 0에 가깝게 유지.
- 무료 입문 전자책(모바일 세로형, 이미 보유) → 이메일·텔레그램 리스트 → 유료 번들 → 엔진 B 안내.

### 6.2 수익 수학 (가정)

| 시나리오 | 월 판매 | 월 매출 |
|---|---|---|
| 비관 | 단권 50 + 번들 20 | 약 $2,000 ≈ ₩280만 |
| 중립 | 단권 100 + 번들 100 | 약 $6,800 ≈ ₩950만 |
| 낙관 | 단권 200 + 번들 150 | 약 $11,000 ≈ ₩1,540만 |

독립 매출로는 작다. 가치는 **엔진 B의 신뢰 자산·리드마그넷**이라는 데 있다. 교육을 거쳐 온 트레이더는 페이백 사이트에서 바로 온 이용자보다 이탈이 적다는 가설을 검증한다.

### 6.3 자동 콘텐츠와 YouTube 정책

- 교육 숏폼(캔들·추세선·유동성 등 53개 챕터 → 수백 편) 자동 생성·게시. 기존 파이프라인 재사용.
- **광고 수익은 계획에 넣지 않는다.** YouTube는 2025년 7월 "반복적 콘텐츠" 정책을 "비진정성(inauthentic) 콘텐츠"로 개명했고, 2026년 7월 16일 추가 설명에서 템플릿 기반 영상, 불만족스러운 콘텐츠, **AI 페르소나가 조언하는 콘텐츠**를 광고 부적격으로 분류했다. 출처: [TechCrunch](https://techcrunch.com/2026/07/20/youtube-clarifies-policies-around-ai-slop-and-upsetting-videos/), [AIR Media-Tech](https://air.io/en/monetization/youtube-monetization-policy-changes-2026-a-complete-dated-timeline). TTS 음성에 AI 아바타가 설명하는 자동 채널은 정확히 이 범주에 들어갈 수 있다.
- 따라서 채널의 목적은 **링크 클릭(유입)**이고, 수익은 전자책·페이백에서 난다. 채널 자체가 제재받으면 유입만 잃고 매출 구조는 유지된다.
- 완화책: 사용자가 1회 녹음한 실제 음성·얼굴 자산을 템플릿에 섞는 방식은 정책 리스크를 낮출 수 있으나, "풀 자동화"와 상충하므로 선택 사항으로 둔다.

### 6.4 교육과 시그널의 경계

- 교육(개념·원칙·사례)은 문제 없다.
- "지금 롱/숏", 특정 종목·시점 추천, 1:1 조언으로 넘어가면 성격이 바뀐다. 한국의 2024년 자본시장법 개정은 유사투자자문업자의 양방향 유료 리딩방과 1:1 조언을 금지했고(3년 이하 징역 또는 1억 원 이하 벌금), 가상자산은 자본시장법 적용 대상은 아니지만 디지털자산기본법 입법이 진행 중이다. 출처: [금융위원회](https://www.fsc.go.kr/no010101/75847), [대륜](https://www.daeryunlaw.com/newsletter/news/71). **유료 시그널은 이 플랜에 넣지 않는다.** Signalmarket 자산은 시장 관찰·교육용 "시나리오 설명" 콘텐츠 생성기로만 쓴다.

### 6.5 킬 기준

## 7. 통합 시나리오

### 7.1 18개월 시점 월 매출 (가정 기반 추정)

| 엔진 | 비관 | 중립 | 낙관 |
|---|---|---|---|
| A 사주 | ₩1,500만 | ₩4,000만 | ₩8,000만 |
| B 해외 페이백 | ₩500만 | ₩2,500만 | ₩5,000만 |
| C 교육 | ₩300만 | ₩1,000만 | ₩2,500만 |
| **합계** | **₩2,300만** | **₩7,500만** | **₩1억 5,500만** |

중립 시나리오에서 8천만은 **18~24개월** 구간에서 도달한다. 비관 시나리오에서는 도달하지 못한다. 어느 시나리오가 실현될지는 엔진 A의 60일·90일 지표(§4.9)에서 가장 먼저 드러난다.

### 7.2 중립 시나리오 월 비용 (가정)

| 항목 | 금액 |
|---|---|
| 인프라(VPS, Supabase, Vercel, 도메인, 알림톡) | ₩30~50만 |
| AI API(리포트 3,000~5,000건 + 콘텐츠 생성) | ₩150~200만 |
| TTS·영상 렌더 | ₩30~50만 |
| 광고(A 매출의 20~30%, ROAS 룰 기반) | ₩800~1,200만 |
| 결제 수수료(A+C 3.5%) | 약 ₩175만 |
| 운영 파트타임 1명(Phase 4부터) | ₩150~250만 |
| 법률·세무(월 평균) | ₩50만 |
| **합계** | **약 ₩1,400~2,000만** |

B의 사용자 페이백 지급은 §5.3 산식에서 이미 차감된 순액 기준이다.

### 7.3 순이익

중립 매출 ₩7,500만 − 비용 ₩1,400~2,000만 ≈ **세전 ₩5,500~6,100만**. 순이익 8천만을 목표로 하면 매출 약 1억 2천만 이상이 필요하고, 낙관 시나리오에 가깝다.

### 7.4 초기 예산 3안

| 안 | 월 예산 | 가능한 것 | 제약 |
|---|---|---|---|
| 1 | ₩100만 | 인프라 + AI + 최소 광고 테스트 | 유입은 오가닉 전적 의존, 속도 느림 |
| 2 | ₩300만 | 위 + 소재 테스트 광고 + 법률 자문 | 권장 최소선 |
| 3 | ₩500만 | 위 + 검증 소재 확장 광고 | ROAS 임계 넘긴 뒤에만 의미 있음 |

배경 자료 §24가 말하듯 실제 가용 자금이 미확인이다. Phase 0에서 확정한다.
