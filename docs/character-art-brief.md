# 캐릭터 이미지 제작 지시서 (사주도감 MVP)

이 문서대로 파일을 만들어 `mvp/saju/assets/characters/<id>/` 에 넣으면 코드 수정 없이 바로 반영된다. 파일이 없으면 지금처럼 SVG 엠블럼이 대신 나온다.

`master`는 실존 인물이다. 사진이든 일러스트든 **본인 서면 동의와 계약이 먼저**다. 동의 전에는 실루엣이나 가칭 일러스트로 두고, 이름 옆 "제휴 전문가 · 감수 전" 표기를 유지한다.

## 2. 캐릭터당 필요한 파일 (총 7장)

모두 **PNG, 투명 배경, sRGB**. 파일명은 소문자 고정. 이미지 안에 글자·로고를 넣지 않는다.

| 파일명 | 크기 | 용도 | 구도 지시 |
|---|---|---|---|
| `full.png` | 1024×1536 (2:3 세로) | 캐릭터 소개 화면, 리딩 화면 | 전신 또는 7부. 정면에서 약간 **왼쪽을 향한 3/4 측면**(말풍선이 오른쪽에 붙음). 발끝·머리끝 여백 각 5%. 시선은 카메라 |
| `face.png` | 1024×1024 | 결과 화면 초상, 리포트 장 머리 | 가슴 위 흉상. 얼굴이 캔버스 높이의 50~60%. 기본 표정 |
| `face_smile.png` | 1024×1024 | 3줄 결과 중 강점 문장, 리포트 요약 | `face.png`와 **완전히 같은 프레이밍·조명·크기**, 표정만 미소/강조 |
| `face_serious.png` | 1024×1024 | 3줄 결과 중 약점·경고 문장, 주의 달 | 같은 프레이밍, 표정만 진지/경고 |
| `face_talk.png` | 1024×1024 | 말풍선 타이핑 중 입 모양 교차 | 같은 프레이밍, 입만 살짝 벌림 |
| `emblem.png` | 512×512 | 카드 모서리, 공유 카드, 파비콘 대체 | 캐릭터의 상징물 1개만(불꽃·엽전·달·연꽃·육각·나침반). 단색 또는 2색 |
| `card.png` | 1080×1350 (4:5) | 공유 카드 배경 | 반신, 캐릭터가 **오른쪽 1/3**에 치우치고 왼쪽 2/3는 비움(글자 들어감). 배경 투명 |

표정 4장(`face*.png`)은 반드시 **같은 원본에서 표정만 바꾼 것**이어야 한다. 프레이밍이 1픽셀이라도 다르면 교차할 때 튄다. AI 생성이라면 같은 시드·같은 프롬프트에서 표정 단어만 바꾸고, 얼굴 위치를 맞춰 크롭한다.

## 3. 스타일 통일 규칙 (6명이 한 세계관처럼 보이게)

- **렌더 방식 통일**: 전원 같은 기법(예: 셀 셰이딩 2톤 + 부드러운 림라이트). 한 명은 수채화, 한 명은 3D 식으로 섞지 않는다.
- **조명 통일**: 광원은 화면 **왼쪽 위 45°**, 캐릭터 강조색의 림라이트가 **오른쪽 윤곽**에 얇게 들어감.
- **선 굵기 통일**: 외곽선은 1024px 기준 3~4px, 내부선 1.5~2px. 선 없는 스타일이면 전원 선 없음.
- **색**: 각 캐릭터의 강조색이 의상·소품·눈동자 중 최소 두 곳에 들어감. 배경은 투명이라 색이 없음.
- **눈높이 카메라**: 전원 눈높이. 동자만 약간 위에서 내려다보는 각도 허용.
- **금지**: 글자, 워터마크, 그라데이션 배경, 실제 브랜드 로고, 실존 연예인 얼굴.

## 4. 연출용 추가 파일 (선택, 있으면 더 좋음)

| 파일명 | 스펙 | 용도 |
|---|---|---|
| `idle.webm` | 1024×1536, 투명(VP9 alpha), 3~4초 루프, 24fps | 캐릭터 소개 화면에서 숨쉬기·머리카락 흔들림 |
| `layers/` 폴더 | `body.png`, `hair.png`, `eyes_open.png`, `eyes_closed.png`, `mouth_closed.png`, `mouth_open.png` (전부 1024×1536 같은 좌표계) | 코드로 눈 깜빡임·입 움직임을 만들 때. 이게 있으면 `face_talk.png` 없어도 됨 |

둘 다 없어도 CSS로 숨쉬기·부유·등장 연출은 들어간다. 레이어 PNG가 가장 적은 용량으로 가장 자연스러운 결과를 낸다.

## 5. 납품 체크리스트

- [ ] 6명 × 7장 = 42장, 파일명·크기·투명 배경 확인
- [ ] 표정 4장 프레이밍 일치(겹쳐 보기)
- [ ] 1024px 기준 눈·입이 모바일 72px 초상에서도 읽히는지(축소해 보기)
- [ ] 각 PNG 1MB 이하(용량 크면 TinyPNG 등으로 압축)
- [ ] `master`는 본인 동의서 사본과 함께

## 6. AI 이미지 생성 시 프롬프트 뼈대 (참고)

```
[캐릭터 설명], [나이/성별], [의상], [소품],
3/4 view facing slightly left, eye-level camera, looking at viewer,
cel shading with soft rim light from top-left, clean 3px outline,
accent color [HEX] on clothing and eyes, plain transparent background,
no text, no logo, full body, 2:3 portrait
```
표정 변형: 끝에 `neutral expression` / `warm smile` / `serious warning expression` / `mouth slightly open mid-sentence` 만 바꾼다.
